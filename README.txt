BATTLE OF FINANCE — DIGITAL PORTAL (V2)

TO PREVIEW:
Open index.html in a modern browser. All site files and the assets/ folder must stay together.

TO PUBLISH FREE WITH GITHUB PAGES:
1. Create a public GitHub repository named battle-of-finance.
2. Upload index.html, styles.css, script.js, and the entire assets folder into repository root.
3. Repository Settings > Pages > Deploy from branch > main / (root) > Save.
4. Wait for the live URL to appear in Settings > Pages.

HOW TO UPDATE:
- Edit content, names, House descriptions, and battleground definitions in script.js.
- Replace placeholders only when the Governing Council approves official mechanics, scores, dates and officers.
- Registration is NOT yet connected. Configure an approved Google Form for each battleground, then add links in gamePage() in script.js.
- The public website must not expose private student information, registration response sheets, or credentials.
- Keep the PDF-derived visual assets as approved; do not substitute generated crests.
- Fonts are loaded from Google Fonts when internet is available; fallbacks work offline.
